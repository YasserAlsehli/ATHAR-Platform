# أثر | النسخة المطوّرة

حزمة تطوير قابلة للتشغيل على Streamlit. لم تُرفع تلقائيًا إلى GitHub أو المنصة المنشورة.

## التشغيل

استخدم Python 3.11 أو أحدث، ثم من داخل مجلد الحزمة:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## تحديث المنصة الحالية

1. احتفظ بنسختك الاحتياطية.
2. ارفع محتويات هذه الحزمة إلى مستودع المنصة بنفس ترتيب المجلدات. هذه النسخة تحتاج app.py وcore.py وexports.py ومجلدي data وassets؛ استبدال app.py وحده لا يكفي.
3. حدّث requirements.txt ثم أعد تشغيل التطبيق في Streamlit Cloud.
4. راجع اختيار المنطقة، العربية والإنجليزية، الخريطة والتنزيل من رابطك الفعلي.

لا ترفع ملف أسرار إلى GitHub.

## المنفّذ

- الهوية الكحلية والفيروزية، افتتاحية المشكلة والفكرة والحل والقرار، جولة اختيارية قابلة للإعادة.
- عشرة أقسام: دمج رحلة الاستخدام مع مركز مصادر جديد؛ حفظ المنطقة بين الأقسام واللغة في الروابط.
- شرح الرسوم والمؤشرات، فصل مقدار الفجوة عن اتجاهها، جدول بفرز وتنزيل CSV.
- بطاقة قرار بالقيم والتفسير والحساب قبل التقريب والتوصيات المشروطة والبيانات المطلوبة.
- خريطة حدود لـ13 منطقة من geoBoundaries؛ الإسناد والترخيص في MAP_SOURCE.md. ليست مرجع ترسيم رسميًا.
- مقارنة منطقتين باستنتاج محسوب من النتائج الحالية.
- عرض عضوية K-Means المحفوظة وملخصات وصفية؛ دون إعادة تدريب أو اختلاق متغيراته.
- موجز PDF للمنطقة وملخص تنفيذي بالعربية والإنجليزية.
- وضع عرض، رسائل خطأ، مؤشرات تحقق، مساعد محلي نصي وربط اختياري بنموذج لغوي.

## تفعيل المحادثة اللغوية

الوضع المحلي يعمل دون مفتاح للخدمات الخارجية، لكنه يعتمد قواعد للأسئلة الشائعة وليس نموذج محادثة عامًّا.

في Secrets على الاستضافة، أضف:

```toml
OPENAI_API_KEY = "ضع مفتاحك هنا في إعدادات الاستضافة فقط"
OPENAI_MODEL = "اسم نموذج متاح في حسابك يدعم Responses API"
PUBLIC_APP_URL = "https://athar-saudi-platform.streamlit.app/"
MAX_REQUESTS_PER_HOUR = "20"
```

الربط يستخدم https://api.openai.com/v1/responses، بحد 800 رمز للإجابة، وسياق يضم النتائج المعتمدة ومسارات الدراسة، ودون حفظ الطلب عبر store. المفتاح يبقى على الخادم. توجد مهلة اتصال وإجابة محلية بديلة عند تعذر الاتصال. قد يستهلك تفعيل النموذج رصيدًا بحسب الخدمة المختارة. لم يُختبر الاتصال الحي لعدم توفر مفتاح. لا تُدخل مفتاحك في المحادثة.

الضوابط الحالية لكل جلسة فقط؛ لا تمثل ميزانية عامة أو حماية كافية لخدمة عامة. قبل فتح المساعد للعامة: ضع سقف إنفاق لدى المزود وحدودًا عامة مع تحقق مستخدمين أو بوابة عند الحاجة، وراجع صحة الإجابات. التعليمات الموجهة للنموذج تقلل الانحراف ولا تضمن انعدام الأخطاء؛ مرجع القرار هو القيم المعتمدة في البطاقات.

## التوثيق الناقص

ملفا CSV المرفقان هما الدليل المباشر للأرقام. لا يحتويان تواريخ الرصد أو تعريف الفئات أو روابط المصادر الأصلية أو خطوات التنظيف أو مبررات حدود التصنيف أو متغيرات K-Means وإعداداته ومقاييسه. توضح المنصة غياب هذه المعلومات.

يمكن إضافة روابط المصادر وملاحظاتها في data/documentation.json، وتعبئة notebook_url وreport_url بعد التحقق من الروابط. عرض متغيرات التدريب يحتاج قراءة الدفتر الفعلي وإضافتها، ولم يُستبدل ذلك بالتخمين.

## التشغيل المستمر

هذه الحزمة لا تنقل الاستضافة ولا تزيل نوم Streamlit Cloud. تشغيل مستمر يتطلب استضافة تدعم عملية Python طويلة التشغيل مع إعادة تشغيل تلقائية ومراقبة صحة من /_stcore/health، وسجل أخطاء وتنبيه عند فشل الفحص. راقب استهلاك النموذج وحدود المزود. لا يوجد ضمان بعدم الانقطاع. لم يتم إعداد استضافة أو تنبيه خارجي من هذه الجلسة.

## التحقق

راجع QA_REPORT.md للفحوص المنفذة وحدود التحقق. لم تكتمل معاينة المتصفح في البيئة الحالية؛ تشغيل Streamlit غير متاح في خادم المعاينة المنفصل هنا. استجابة النقر على الخريطة وتخطيط الجوال ولوحة المفاتيح تحتاج مراجعة من التطبيق الفعلي. بديل اختيار المنطقة من القائمة الجانبية متاح دائمًا.
