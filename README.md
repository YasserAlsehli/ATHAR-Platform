# ATHAR | أثر

An interactive, bilingual decision-support platform
for exploring regional distribution indicators
related to Saudi Arabia's nonprofit sector.

## Features
- Arabic and English interface
- Regional distribution analysis
- Regional priority exploration
- Interactive comparisons
- Data-driven analytical assistant
- Interactive charts and data export

## Methodology
The distribution gap is measured in percentage points:

Beneficiaries share (%) - Organizations share (%)

Priority classifications are exploratory indicators,
not direct evidence of unmet service needs.

## Technology
Python, Pandas, NumPy, Plotly, Scikit-learn, Streamlit.
